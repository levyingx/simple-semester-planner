### Semester Planner App

**Summary:**
The system is supposed to be an interactive version of my university's academic 
transcript. Also counts with a simple semester planner so I don't have to load Google 
Sheets every time to look this info up. It also serves as a small playground for me 
to experiment and learn about lifespan, versioning and scalability of a project.

**Stack:**
- HTML;
- SCSS;
- JavaScript;
