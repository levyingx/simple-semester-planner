### <b>Miniworks</b> Sage

**Summary:**
This cool-named system is a supposed to be an interactive version of my university's academic 
transcript. Also counts with a semester schedule planner so I don't have to load Google Sheets every time to look this info up. It also serves as a little sandbox for me 
to experiment and learn about lifespan, versioning and scalability of a project.
