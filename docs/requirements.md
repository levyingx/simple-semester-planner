This system is divided into three main pages:

- A "User Settings" page. Kind of an account settings, but you can manually set personal data up. (See the "Dados do Vínculo do Discente" section).
- A "Semester Planner" page. Contains an interactive timetable and a list on the right side.
- A "Course Completion" page. Acts as a dashboard and the user should be able to simulate workload completion.

**User Requirements:**
- [x] The "Semester Planner" page should be the index page;
- [ ] The timetable should be minimally responsive;
- [ ] The timetable should hopefully fit my screen height;
- [ ] The timetable should be composed of color coded cells;
- [ ] When I hover over a timetable cell, the background color of the respective list's subject item should change to the same color;
- [ ] The time cells should come with the code version by default;
- [ ] I should be able to switch between the hour format (e.g.: 2h40) and the coded format (e.g: T4) by clicking the time cells;
- [ ] I should be able to switch between the weekday format (e.g.: Segunda), the its shortened version (e.g.: S) and the number format (e.g: 2) by clicking the timetable's thead;
