This system is divided into three main pages:

- A "User Settings" page. Kind of an account settings, but you can manually set personal data up. (See the "Dados do Vínculo do Discente" section).
- A "Semester Planner" page. Contains an interactive calendar and a list on the right side.
- A "Course Completion" page. Acts as a dashboard and the user should be able to simulate workload completion.

- The user should use a sidebar on the left to navigate between the pages.
